# To-do List

Веб-приложение для управления повседневными задачами. Позволяет создавать списки дел, распределять задачи по папкам и категориям, отслеживать выполнение и настраивать внешний вид интерфейса.

## Реализованные функции

### Управление задачами

- Добавление новых задач.
- Редактирование существующих задач.
- Удаление задач.
- Отметка задач как выполненных.
- Отмена последнего удаления.
- Изменение порядка задач вручную.
- Автоматическое перемещение выполненных задач в конец списка.
- Назначение приоритета задачам.

### Поиск и фильтрация

- Поиск задач по названию.
- Фильтр «Все».
- Фильтр «Активные».
- Фильтр «Выполненные».

### Папки и категории

- Создание личных папок.
- Создание категорий.
- Организация задач по папкам и категориям.

### Настройки интерфейса

- Светлая тема.
- Тёмная тема.
- Сохранение выбранной темы.

### Сохранение данных

- Использование `localStorage` для хранения задач и пользовательских настроек.
- Данные сохраняются в браузере после перезагрузки страницы.

## Технологии

- HTML5 — структура приложения.
- CSS3 — оформление и адаптивный интерфейс.
- JavaScript — логика и интерактивные функции.
- localStorage — локальное хранение данных.
